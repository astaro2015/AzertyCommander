# AZERTY Commander

Упрощенный двухпанельный файловый менеджер под Windows.

## Возможности

- две независимые панели с дисками, путями, сортировкой и мультивыделением;
- системные иконки папок и файлов;
- избранные каталоги в каждой панели с добавлением/удалением и горячей клавишей Ctrl+D;
- верхняя панель быстрых иконок;
- пользовательские значки быстрого запуска с сохранением в профиле Windows;
- окно настроек для шрифтов, межстрочного отступа (от 0 пикселей) и цветов панелей;
- F3 просмотр текстовых файлов;
- F5 копирование в соседнюю панель с прогрессом, скоростью и примерным остатком времени;
- F6 перемещение в соседнюю панель с прогрессом, скоростью и примерным остатком времени;
- F7 создание папки;
- F8 или Delete удаление в корзину в фоне с окном процесса;
- Shift+Del удаление безвозвратно с подробным прогрессом по файлам и папкам;
- Ins выделение текущей строки с переходом вниз;
- Space выделяет текущую строку без перехода вниз; на папке считает и показывает размер содержимого;
- Tab переключает только активную левую/правую панель;
- Num+ и Num- добавляют или убирают выделение по маске/шаблону;
- Num* выделяет все элементы активной панели;
- F2 переименование;
- Ctrl+M групповое переименование с масками `[N]`, `[E]`, `[C]`, регулярными выражениями, ручной правкой новых имен, шаблонами, историей и отменой последней операции;
- спокойный второй клик по уже выбранному файлу или папке запускает переименование;
- правый клик по файлу или папке открывает стандартное меню Windows;
- Ctrl+F поиск по маске/вхождению, месту поиска, глубине, дискам, тексту, размеру и дате изменения без подвисания интерфейса;
- найденное из окна поиска можно вывести в активную панель и работать с ним как со списком файлов;
- побайтовое сравнение двух файлов, выбранных на левой и правой панели;
- рекурсивное сравнение двух открытых каталогов по дате/размеру, SHA-256 или побайтово, с фильтром, цветами отличий, синхронизацией и зеркальным режимом;
- разрешение конфликтов копирования: заменить, пропустить или сохранить оба файла, в том числе сразу для всей операции;
- общая очередь локальных и сетевых операций: копирование, перемещение, удаление, архивы, FTP/SFTP, вставка, Drag & Drop и синхронизация; видны скорость, оставшееся время и текущий файл, доступны пауза, отмена, повтор, перестановка и автоматическое скрытие после завершения;
- расчет CRC32, MD5 и SHA-256, поиск файлов-дубликатов по размеру и SHA-256;
- окно свойств файла или папки по Alt+Enter: размер, даты, атрибуты, версия, цифровая подпись и хеши;
- упаковка выделенного в ZIP с прогрессом, скоростью и примерным остатком времени;
- распаковка ZIP, 7z и RAR в соседнюю панель;
- ZIP, 7z и RAR открываются как папки, а F5 распаковывает выбранное в соседнюю локальную панель;
- в ZIP можно добавлять, переименовывать и удалять элементы прямо из панели; 7z и RAR открываются только для чтения;
- распаковка ZIP подбирает кодировку имен, включая старые русские архивы CP866/Windows-1251;
- ZIP создается сразу в противоположной панели;
- боковая кнопка мыши назад выходит на уровень выше, вперед входит в папку под курсором;
- Ctrl+C/Ctrl+Insert копируют файлы в буфер, Ctrl+X вырезает, Ctrl+V/Shift+Insert вставляют;
- Ctrl+Shift+Enter в командной строке вставляет полный путь текущего файла или папки в кавычках;
- Drag & Drop между панелями, из Проводника в панель и из панели в Проводник;
- менеджер сохраненных соединений FTP, FTPS и SFTP с подключением прямо в активную панель, keep-alive и автоматическим переподключением;
- F5/F6 между локальной и удаленной панелью скачивают или закачивают выбранные элементы через общую очередь с прогрессом, скоростью, ограничением скорости и продолжением прерванной передачи;
- в FTP-панели работают Enter/Back для навигации, F7 новая папка, F2 переименование и F8 удаление;
- встроенный FTP сервер для выбранной папки с anonymous/логин-паролем, read-only режимом, адресами и журналом;
- сборка x64 и x86 в отдельные самодостаточные `.exe`, для запуска которых не требуется установленный .NET;
- автоматическое увеличение версии при каждой обычной компиляции.

Файлы в быстрый запуск можно добавить правым кликом по пустому месту верхней панели или перетаскиванием файла на панель. Правый клик по пользовательскому значку позволяет запустить его, открыть папку или убрать с панели.

При перетаскивании файлов в панели обычный бросок копирует, Shift принудительно перемещает. При перетаскивании из панели в Проводник программа тоже просит Windows копировать по умолчанию. Если бросить элемент на строку папки, операция идет внутрь этой папки; на пустом месте - в текущий каталог панели.

Сетевые подключения находятся в меню `FTP` и на верхней панели значков. Менеджер профилей в стиле Total Commander умеет обычный FTP, FTPS с явным TLS и SFTP. После выбора профиля активная панель переключается в удаленный режим, а соседняя панель работает как целевая для F5/F6. Встроенный сервер использует пассивный обычный FTP без TLS. Для локальной сети обычно достаточно порта 2121 и разрешения в брандмауэре Windows; для доступа из интернета нужен проброс основного порта и PASV-диапазона или VPN/туннель.

Программа запоминает размер и положение окна, разделитель панелей, последние пути, избранные каталоги, ширины столбцов, шрифты, цвета и быстрый запуск в `%LOCALAPPDATA%\AZERTY Commander`.

## Сборка

```powershell
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true
```

Каждая обычная компиляция поднимает build-номер в `version.json`, обновляет версию в окне/свойствах `.exe` и добавляет строку в `VERSION_HISTORY.md`. Для технического запуска без увеличения версии можно передать `-p:SkipVersionBump=true`.

Для готового релиза x64 и x86 с одинаковым номером версии:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\publish-ready.ps1
```
